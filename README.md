# Time Counter Website
A basic website that shows the time that you entered the website, and counts the time spent on the website. The timer will keep on counting forever, as long as you are on the page. If you reload the website, the counter will reset back to zero. It is made without using HTML tags.

This is an example of my website in action.

In the center you can see how long you have been on the website. There is a pulsing loading circle that lasts 10 seconds, and after 10 seconds the background colour changes. Also, there is a larger ring on the outside that counts for 5 minutes.

At the bottom of the screen it shows at what time you entered the site.

There may be a surprise at 5 minutes... if you can be bothered to wait that long...
